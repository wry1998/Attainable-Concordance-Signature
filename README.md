# Attainable Concordance Signature on Swiss Market Index

Under the supervision of Professor Johanna Nešlehová, I conducted an undergraduate research project motivated by [McNeil et al., 2022](#mcneil2022) on attainable concordance signatures. I proposed an applied study using the Swiss Market Index (SMI), which contains 20 constituents with two lack complete histories.

This project aimed to answer the following questions:

- How can we study multivariate dependence when some components' data are not available?
- What does the attainable set of concordance signatures look like on Swiss Market Index?
- How can we reduce dimensionality when the computation of concordance signatures scales exponentially with dimension?

------------------------------

## Data

The dataset contains the **adjusted daily prices of the 20 SMI constituents in 2020**, downloaded from Yahoo Finance. After cleaning:

- 18 stocks have nearly complete histories. 
- PGHN has only a partial history, as it was newly added to the index after September 18, 2020.
- ALC is treated as fully missing, since its price is in different currency from the other stocks.

To remove auto-correlations driven by volatility clustering, I first transformed prices into **log returns** and then fitted a **GARCH(1,1)** model to each stock using either **Gaussian** or **scaled-t innovations**.

Model adequacy was checked using:

- **auto-correlograms** of absolute residuals, and
- **Portmanteau tests** of strict white noise, and
- **QQ plots** and **histograms** for residuals to check Gaussian or scaled-t innovations.

The resulting standardized residuals were treated as approximately **i.i.d.** and follows **elliptical distribution**.

------------------------------------------------------

## Methodology

For a set of variables $\mathcal{D}$, the **concordance signature** is the collection of the probabilities of concordance over subsets of $\mathcal{D}$. By [McNeil et al., 2022](#mcneil2022), odd concordance signatures can be derived from even ones, so the concordance signature is determined soley by the probabilities of concordance of even subsets. While given the partial concordance signature on a set $\mathcal{D}$, only some values of the remaining concordance signature is attainable, and this attainable set forms a **convex hull** generated by extremal mixture copulas.

Using this framework, I analyzed the dependence structure of SMI: even though we could not estimate the full concordance signature due to incompleteness of PGHN and ALC, we could study the **attainable concordance signature**, given the partial concordance signature of the stocks with completed histories. Note that the partial concordance signature is estimated using the multivariate Kendall's tau, via the methodology introduced in [McNeil et al., 2022](#mcneil2022).

## Empirical Results

The computation of attainable concordance signature is done via R package [`KendallSignature`](https://github.com/ajmcneil/KendallSignature). Since this package always calculates the full set of concordance signature, which scales as **$O(2^d)$**, computation time was a major obstacle in this study. I tried several approaches to resolve this issue:

- Clustering the stocks into PEA clusters, and
- Setting higher-order concordance terms to zero, and
- Starting with a small subset then generalizing the result to a higher dimension.

### Dimension reduction via PEA clustering

The first approach I tried was partitioning the stocks into clusters that satisfy the **Partial Exchangeability Assumption (PEA)**, so that any stock from a cluster can be used to represent the entire cluster in the study of dependence. I applied the algorithm in [Perreault et al., 2019](#Perreault2019) (I leveraged the code in [learning-block-exchangeability](https://github.com/samperochkin/learning-block-exchangeability/tree/master)) to search for the optimal partition that would create the least number of clusters while not rejecting PEA, and **compressed the 18 stocks to 13 clusters**. However, 15 (13 clusters + PGHN + ALC) was still too expensive to compute directly, so I had to consider other approaches.

Note that a useful practical observation from this step was that clusters formed by industry often contain multiple clusters that satisfy PEA, and that they rarely split a PEA-based cluster. This makes the industry-based clusters **a strong initialization** for the partition algorithm.

### Attainability of higher-order independence 

Another approach was to **set the probabilities of concordance to be zero for all subsets with cardinality larger than 2** (i.e. assume higher-order independence, which is a commonly used simplification in practice), but I had to verify it's attainability first. 

I chose several subsets of stocks from SMI to apply the attainability check. I first estimated the even concordance signature using the data directly, then set $\kappa_I = 0$ for every $|I| > 2$, and checked its attainability via the `attainable()` function in [`KendallSignature`](https://github.com/ajmcneil/KendallSignature). Unfortunately, after checking on several subsets, I concluded that higher-order independence was in general not attainable in this case.

### Attainable concordance signature on SMI

I started with a small subset, $\mathcal{D} =$ {UBSG, LHN, LONN, PGHN}. I estimated the set of attainable concordance signature given the partial concordance signature on {UBSG, LHN, LONN}, and plotted the attainable set. Then, I repeated this experiment by adding more stocks into $\mathcal{D}$. I focused on a lower projection of the attainable set as it is easier to visualize, and discovered that the lower projection remains the same as more stocks were added. For example, the set of attainable pairwise concordance forms a rectangle on the 2-D projection of PGHN-UBSG and PGHN-LHN, and this rectangle remains the same when adding more stocks to the given partial concordance signature.

I also estimated the full concordance signature on $\mathcal{D}$ using the common observation window shared by all stocks (i.e. data after September 18, 2020), and verified that above attainable concordance signature captures this estimation. 

----------------------------------------------

## Limitations

This project was mainly limited by two factors.

First, a more fundamental solution to the computational obstacle would be modifying the R package `KendallSignature` to allow computing only the partial attainable concordance signature relevant to the target stocks. Due to time constraints, I was not able to fully study and revise the package code, therefore used above practical approaches. 

Second, I empirically found that lower-dimensional projections of the attainable set appeared unchanged as additional stocks were added, but did not have the opportunity to establish it mathematically.
